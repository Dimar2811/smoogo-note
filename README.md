# SmooGo Note – Website

Statische Produkt-, Datenschutz- und Support-Seiten für SmooGo Note (iPhone, iPad, Mac), gehostet mit GitHub Pages.

- `/` Startseite mit den interaktiven Lehrmodellen der App
- `/datenschutz/` und `/en/privacy/` – Datenschutzerklärung (spiegelt `PrivacyPolicyView` in `Sources/NoteCore/AppAbout.swift`)
- `/support/` und `/en/support/` – Hilfe und Kontakt

`assets/palettes.css` ist aus `StudyPalette` in `Sources/NoteCore/StudyDiscipline.swift` erzeugt, `assets/study.js` portiert `StudyScenes.swift`. Die Bilder sind die eigenen Cycles-Renders der App (jedes zweite Frame). Keine Cookies, keine Analyse, keine Inhalte von Dritten.
